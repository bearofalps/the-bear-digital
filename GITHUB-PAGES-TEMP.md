# Temporary GitHub Pages deployment

This package intentionally contains **no `CNAME` file** so GitHub Pages can use the default project URL first.

Recommended temporary repository name: `the-bear-digital`

Temporary URL after GitHub Pages is enabled from `main` / root:

`https://bearofalps.github.io/the-bear-digital/`

When the custom domain is ready, add `CNAME` containing:

`bearbook.alpskimedved.xyz`

Then configure the matching DNS CNAME and GitHub Pages custom domain.
